# WRC 9 遥测仪表盘 · 使用说明

本地运行的 WRC 9 实时遥测仪表盘（独立桌面窗口，适合 OBS 直播采集）。
数据链路：WRC 9 →（第三方补丁写入共享内存）→ 本工具直读显示。
**不需要转发器、不需要端口/防火墙配置**，装好补丁 → 开游戏 → 开仪表盘即可。

---

## 一、快速开始（无游戏自测）

1. 双击 **`启动仪表盘.bat`**（或命令行运行 `python dashboard/main.py --sim`）。
2. 点工具栏 **「▶ 启动模拟器 (S)」**，立即出现合成数据（转速扫频、自动换挡、
   G 值扰动）——数据由内置合成源直接生成，不经过任何网络。
3. 快捷键：**S** 模拟器 · **T** 置顶 · **G** 绿幕 · **H** 隐藏工具栏 · **Q** 退出。

## 二、直播（OBS）配置

1. OBS → 来源 → 添加 **「窗口采集」** → 窗口选 `WRC 9 遥测仪表盘`，
   采集方式选 **「Windows 10 (1903 及以上)」**（该方式才能保留透明）。
2. 仪表盘按 **G** 进入透明模式：窗口背景直接变透明（无需再挂色键滤镜），
   只剩仪表叠在画面上；再按 **G** 返回普通模式。
   - 透明原理是“指定颜色抠除”，因此透明模式下配色会自动切换成高对比、
     无绿色系主题（油门条等会变成蓝色），这是正常的。
   - 透明区域会“点击穿透”，拖窗口请用标题栏。
   - 若你的采集方式较旧、透明区显示为黑色：把 `config.json` 里
     `"transparent"` 改为 `false`，回到“绿幕 + OBS 色键滤镜”的老办法。
3. 按 **T** 窗口置顶、**H** 隐藏工具栏，画面只剩仪表。窗口位置和大小会自动记忆。

## 三、连接真实 WRC 9（关键步骤）

WRC 9 没有官方遥测接口，需要第三方补丁（**本工具不包含补丁本体，请自行下载**）：

1. 注册并登录 RaceDepartment，下载 **WRC Telemetry Patch**（WRC 7/8/9/10 通用）：
   https://www.racedepartment.com/downloads/wrc-telemetry-patch.38991/
2. 按补丁自带说明解压到游戏目录，运行一次 `InstallWrc10.bat` 完成安装
   （详见 `patch/安装说明.txt`）。
3. **直接启动 WRC 9，再打开本仪表盘即可**——仪表盘**直读补丁的原生
   共享内存**（与 SimHub 同源），**不需要转发器，也没有端口/防火墙问题**。
4. 左上角状态变为绿色「接收中 xx pkt/s ｜ 模式：共享内存直读」即成功。

## 四、真机校准（已完成，留档备查）

转速/车速/G 值/档位/悬挂均已按真机数据校准好（`config.json`）：
`rpm_scale=10`（补丁转速为真值 1/10）、`g_scale=9.81`（m/s²→G）、
`g_lon_flip=true`（刹车朝上）。

G-G 图小球颜色按占显示半径的比例分四档：红（≥90%）、橙（70~90%）、
黄（50~70%）、绿（<50%）。档位阈值可通过 `config.json` 的
`"gg_thresholds": [0.9, 0.7, 0.5]` 修改（必须是 3 个 0~1 之间严格递减的数，
配置不合法会自动回退默认值）。小球始终限幅在显示半径内。

**协议死字段**：遥测协议本身没有油门/刹车/离合/转向、圈速、里程、燃油。
其中**油门/刹车/转向已由手柄输入补读**（XInput 标准通道：RT=油门、LT=刹车、
左摇杆=转向，与游戏内键位无关；不需要手柄时把 `config.json` 的
`"gamepad"` 设为 `false`）。离合无手柄通道，原位改显**四轮转速**
（来自协议 unknown 字段，经真机鉴定为轮速 rad/s；明显偏慢=抱死、
偏快=打滑，会以橙/红色标出）。

## 五、命令行工具一览

| 命令 | 作用 |
|---|---|
| `python dashboard/main.py` | 启动仪表盘窗口（`--sim` `--topmost` `--green`） |
| `python dashboard/main.py --self-test 8` | 自检：自动开合成数据源，8 秒后打印结果并退出 |
| `python telemetry/wrc_shm.py` | 无界面直读共享内存打印，确认补丁是否在喂数据 |
| `python -m unittest discover -s tests -v` | 运行全部单元测试 |

## 六、常见问题

- **一直「等待数据…」**：说明补丁没装好或游戏没启动——重装
  `InstallWrc10.bat`、确认 `PhysXCooking64_s.dll` 被游戏加载；用
  `python telemetry/wrc_shm.py` 看能否读到数据。
- **转速为 0 或明显不对**：检查 `config.json` 的 `rpm_scale` 是否为 10。
- **姿态不显示**：补丁协议无姿态字段，属正常，不影响仪表。
